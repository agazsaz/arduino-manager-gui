# arduino-manager-gui

Лабораторная работа: настройка CI/CD для GUI-приложения на Go (Fyne) с публикацией бинарников в GitHub Releases.

## 1. Разработка и локальный запуск приложения
Приложение "Arduino Manager" написано на Go с использованием библиотеки Fyne. Оно имеет графический интерфейс и позволяет управлять подключенными платами.

## 2. Настройка CI/CD пайплайна (GitHub Actions)
Пайплайн настроен в файле `.github/workflows/release.yml`. Он использует матрицу сборки (Matrix Strategy) для параллельной компиляции приложения под три операционные системы: Linux, Windows и macOS. Сборка автоматически запускается при создании нового тега (например, `v1.0.7`).

**

## 3. Публикация в GitHub Releases
После успешной сборки пайплайн автоматически создает новый релиз и прикрепляет к нему скомпилированные бинарники (включая `.exe` для Windows). Это позволяет пользователям скачивать готовое приложение без необходимости собирать его из исходников.

## Вывод
В ходе работы был настроен полный цикл CI/CD для GUI-приложения на Go. Автоматизирована кросс-платформенная сборка (включая учет специфических зависимостей Fyne для Linux) и публикация релизов. Задачи выполнены в полном объеме.
